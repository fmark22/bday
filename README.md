# 생일 전하

친구들과 선물을 나누고, 생일 주인공을 왕으로 꾸며주는 3D 생일파티입니다.
설치나 회원가입 없이 웹 브라우저로 참여합니다.

[GitHub 저장소](https://github.com/fmark22/bday) · [배포 안내](./DEPLOYMENT.md)

## 파티는 이렇게 진행돼요

1. 손님은 꽃다발·리본·망토·안경 중 선물 하나를 골라 입장합니다.
2. 왕실 집사·궁정 학자·근위병·음유시인 중 한 캐릭터와 이름을 자동으로 받습니다.
3. 주인공은 선물 없이 입장합니다. 주인공이 없는 방에서는 먼저 들어온 손님이 주인공으로 전환할 수도 있습니다.
4. 주인공이 대관식을 시작하고 레드카펫을 따라 왕좌로 이동합니다.
5. 왕좌에 앉아 왕관을 쓰면 생일 음악과 축하 효과가 나옵니다.

손님은 주인공에게 선물을 건네고 박수를 보낼 수 있습니다. 받은 선물은 주인공에게 바로 착용되며, 주인공이 직접 벗거나 다시 착용할 수도 있어요.

## 주요 기능

- **실시간 파티:** 같은 방에서 주인공 1명과 손님 최대 29명이 참여합니다.
- **캐릭터 자동 배정:** 네 종류를 무작위로 섞어 한 명씩 배정하고, 모두 배정하면 다시 섞습니다.
- **선물로 꾸미기:** 꽃다발은 손, 리본은 목, 망토는 등, 안경은 얼굴에 착용됩니다.
- **함께 보는 변화:** 이동·박수·선물 전달·착용 상태와 채팅을 같은 방에 공유합니다.
- **소리:** 잔잔한 배경음, 박수 효과음, 왕관 착용 시 생일 음악을 재생합니다.
- **초대 링크:** 같은 방 주소를 복사해 친구에게 보낼 수 있습니다.
- **체험 화면:** 서버에 연결하지 않고 대관식과 선물을 확인할 수 있습니다.

캐릭터 이름은 별도 닉네임 없이 사용합니다. 같은 방에 5명 이상의 손님이 들어오면 캐릭터와 이름이 겹칠 수 있습니다. 중복 허용 정책은 아직 확정하지 않았습니다.

## 로컬 실행

Node.js **22.x**와 npm이 필요합니다.

```bash
git clone https://github.com/fmark22/bday.git
cd bday
npm ci
npm run server
```

다른 터미널에서 웹 개발 서버를 실행합니다.

```bash
npm run dev
```

브라우저에서 [http://localhost:5173](http://localhost:5173)을 엽니다.
실시간 서버의 기본 포트는 `3001`이며, 개발 서버가 `/socket.io` 요청을 전달합니다. 별도 환경변수 없이 로컬에서 실행할 수 있습니다.
이미 포트를 사용 중이라면 Vite가 출력한 주소를 확인하세요.

### 조작 방법

| 대상 | 조작 |
| --- | --- |
| 주인공 | 대관식 시작 후 카펫 클릭·터치, `W` / `↑` 전진, `S` / `↓` 후진 |
| 주인공 | 왕좌 근처에서 착석 → 왕관 착용 |
| 손님 | 주인공 입장 후 선물 전달, 대관식 시작 후 박수 |
| 모두 | 화면을 끌어 둘러보기, 휠로 확대, 채팅과 소리 버튼 사용 |

소리는 입장 버튼 등 사용자의 동작 후 활성화합니다. 브라우저가 재생을 막으면 사이트의 소리 권한을 확인하세요.

### 방과 미리보기 주소

| 주소 | 용도 |
| --- | --- |
| `/?room=my-party` | `my-party` 방에 참여. 같은 방 코드로 접속해야 서로 보입니다. |
| `/?demo=1` | 주인공과 손님 네 명이 있는 단독 체험. 대관식과 선물 도착을 확인합니다. |
| `/?studio` | 왕과 손님 캐릭터를 회전·확대하고 선물 착용 모습을 살펴봅니다. |

방 코드를 생략하면 `birthday` 방에 입장합니다. 체험 화면과 캐릭터 화면은 실제 다중 접속을 검증하는 용도로 사용하지 않습니다.

## 배포

웹 화면은 **Vercel**, 실시간 서버는 **별도 Node.js 호스팅**에 배포합니다. 두 서비스가 같은 Git 저장소를 사용하며, 프로젝트 루트를 기준으로 설치합니다.

| 설정 | 웹 — Vercel | 실시간 서버 |
| --- | --- | --- |
| 설치·빌드 | `npm ci` → `npm run build` | `npm ci --omit=dev` |
| 실행·출력 | `dist` | `npm start` |
| Node.js | 22.x | 22.x |
| 상태 확인 | 웹 주소 접속 | `GET /health` → `{"ok":true}` |

### 환경변수

| 변수 | 설정 위치 | 값 |
| --- | --- | --- |
| `VITE_SOCKET_URL` | Vercel | 실시간 서버의 HTTPS 주소 |
| `CLIENT_ORIGIN` | 서버 호스팅 | Vercel 웹의 HTTPS 주소 |
| `NODE_ENV` | 서버 호스팅 | `production` |
| `PORT` | 서버 호스팅 | 호스팅에서 제공하는 포트. 생략하면 `3001` |

예시는 [.env.example](./.env.example)에 있습니다. 실제 값은 각 호스팅의 환경변수에 입력하세요. Node 서버는 `.env` 파일을 자동으로 읽지 않습니다.

- 주소에는 `/socket.io` 경로나 `?room=...`을 붙이지 않습니다.
- `VITE_SOCKET_URL`은 빌드할 때 포함됩니다. 변경 후 Vercel에서 다시 배포해야 합니다.
- `CLIENT_ORIGIN`에 여러 웹 주소를 허용하려면 쉼표로 구분합니다. Vercel Preview 주소는 자동으로 허용하지 않습니다.
- 방 상태는 메모리에 있으므로 서버는 **인스턴스 1개**로 운영합니다.

Vercel 설정은 [vercel.json](./vercel.json)에 있습니다. 서버 연결과 배포 후 확인 순서는 [배포 안내](./DEPLOYMENT.md)를 참고하세요.

## 개발 명령

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 웹 개발 서버 실행 |
| `npm run server` / `npm start` | 실시간 서버 실행 |
| `npm run build` | 웹 프로덕션 빌드 |
| `npm test` | 방·선물·캐릭터 배정·GLB 모델·오디오 처리 검증 |
| `npm run test:deploy` | 로컬 서버와 실제 WebSocket 클라이언트 두 개로 연결·동기화·허용 도메인 검증 |
| `npm run build:models` | 캐릭터 5종과 선물 4종의 GLB 재생성 |
| `npm run build:brand` | 왕관 파비콘과 앱 아이콘 재생성 |

`test:deploy`는 로컬 포트를 사용합니다. 테스트와 빌드가 통과해도 배포 주소에서 여러 브라우저·기기의 동작을 별도로 확인해야 합니다.

## 기술 구성

- **웹:** React 19, Vite 6
- **3D:** Three.js, React Three Fiber, Drei
- **실시간 통신:** Socket.IO
- **서버:** Node.js, Express
- **오디오:** Web Audio API
- **글꼴:** 고운돋움. 폰트와 [SIL Open Font License](./public/fonts/OFL-GowunDodum.txt)를 프로젝트에 포함합니다.

```text
client/            화면, 3D 공간, 캐릭터, 오디오
server/            방 상태와 Socket.IO 이벤트
shared/            캐릭터·선물 정의, 체험 화면의 상태 처리
public/models/     캐릭터 5종과 선물 4종 GLB
public/images/     선물 선택 카드 이미지
public/fonts/      고운돋움과 라이선스
public/            파비콘, 앱 아이콘, 웹 앱 매니페스트
design/character/  캐릭터 디자인 시안
tools/             모델·아이콘 제작 스크립트와 검증 도구
```

## 현재 제한사항

- **데이터를 영구 저장하지 않습니다.** 서버 재시작·재배포 또는 마지막 참가자 퇴장 시 방·채팅·선물이 사라집니다.
- 재접속 시 이전 캐릭터·역할·선물 전달 상태를 자동 복구하지 않습니다.
- 주인공은 사용자가 선택합니다. 별도 인증이나 전용 초대 코드는 없으며, 먼저 주인공으로 들어온 한 명을 인정합니다.
- 채팅은 방별 최근 50개 메시지만 보관합니다. 신고·차단 기능은 아직 없습니다.
- 디자인 시안과 선물 카드 이미지는 생성 이미지입니다. 실제 게임은 시안을 참고해 만든 GLB 모델을 사용하며, 세부 표현에는 차이가 있습니다.
- 모델은 계층형 관절로 움직입니다. 정교한 인체 스키닝과 옷감 시뮬레이션은 적용하지 않았습니다.
- 실제 모바일 성능과 최대 30명 동시 접속 부하 검증은 아직 완료하지 않았습니다.
